# Data

Aquí se guardan los archivos `.json` con la información del sistema
(`bibliotecarios.json`, `usuarios.json`, `libros.json`, `prestamos.json`).

Ya incluyen datos de ejemplo (libros, usuarios y préstamos de muestra) para
poder probar el sistema sin tener que registrar todo desde cero. El programa
los actualiza automáticamente cada vez que se agrega, edita o elimina algo.
